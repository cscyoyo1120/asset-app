# 자산관리

휴대폰에서 쓰는 개인 자산관리 웹앱(PWA). 데이터는 **각 사용자의 구글 드라이브에 있는 「자산관리」 시트**에만 저장된다. 서버 없음.

**앱 주소: https://cscyoyo1120.github.io/asset-app/**

- 탭: 대시보드 / 자산(부동산·대출 포함) / 고정(수입·지출, 대출 상환 자동) / 주식(예수금 포함)
- 시트 탭: 자산, 대출, 고정지출, 부동산, 주식, 기록(월별 순자산 자동), 설정(환율 자동)
- 대출: 총액·잔여·금리·기간·상환방식을 넣으면 월 상환액을 계산해 고정지출에 자동 포함, 부동산에 연결하면 본전 시세에 반영
- 주식 현재가: 티커(예: NASDAQ:AAPL, KRX:005930)를 넣으면 GOOGLEFINANCE로 자동
- 권한: `drive.file` — 이 앱이 만든 파일에만 접근
- 시트에서 직접 고쳐도 앱에 반영됨 (1행 머리글 이름은 바꾸지 말 것)
- 로그인 없이 "체험 모드"로도 사용 가능 (그 기기 브라우저에만 저장, 환율은 ECB 기준)

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 앱 전체 |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | 홈 화면 설치(PWA) |
| `serve.bat` | 이 PC에서 테스트 (http://localhost:8080) |

## 1. Google Cloud 설정 (한 번)
1. https://console.cloud.google.com → 새 프로젝트 `자산관리`
2. **API 및 서비스 → 라이브러리**: `Google Sheets API`, `Google Drive API` 사용 설정
3. **OAuth 동의 화면**: 외부(External), 앱 이름 `자산관리`
   - **대상 → 테스트 사용자**에 쓸 사람들의 Gmail 추가 (최대 100명)
   - **데이터 액세스 → 범위 추가**: `.../auth/drive.file`
4. **클라이언트 → 클라이언트 만들기**: 웹 애플리케이션
   - 승인된 JavaScript 원본: `http://localhost:8080`, `https://<깃허브아이디>.github.io`
5. 발급된 클라이언트 ID를 `app.js` 맨 위 `CLIENT_ID`에 넣기 (secret은 필요 없음)

테스트 상태에서는 7일마다 다시 로그인해야 한다. 지인이 많아지면 동의 화면을 "프로덕션"으로 게시.

## 2. 배포 (GitHub Pages)
1. GitHub에 새 저장소 생성 (예: `asset-app`)
2. 이 폴더 내용을 올리기
3. 저장소 **Settings → Pages → Branch: main / (root)** 저장
4. `https://<깃허브아이디>.github.io/asset-app/` 접속 → 휴대폰에서 공유 → **홈 화면에 추가**

## 지인 안내 문구
> 링크 열고 "구글로 시작하기" → "확인되지 않은 앱" 경고가 뜨면 **고급 → 자산관리(으)로 이동** → 허용.
> 내 드라이브에 「자산관리」 시트가 생기고 거기에만 저장돼요. 다른 파일은 볼 수 없어요.

## AI로 데이터 넣기 (캡처 → JSON)
1. 앱 **⋯ → AI로 데이터 가져오기 → AI 안내문 복사**
2. ChatGPT·Claude·Gemini 등에 안내문을 붙여넣고 **은행·증권·대출 앱 화면 캡처**를 함께 보냄
3. AI가 준 JSON을 앱 입력칸에 붙여넣기 → **바꾸기**(들어 있는 항목만 교체) 또는 **추가**(기존 뒤에 덧붙임)

- 형식 정의는 앱 코드의 `SHEETS`(desc·ai)에서 자동 생성되므로 필드를 바꾸면 안내문도 같이 바뀜
- AI 답변에 설명·코드블록이 섞여 있어도, `"1,250,000원"`·`"25일"`·`"3.9%"`처럼 써도 정리해서 받음
- 캡처 화면이 AI 서비스로 전송되니, 계좌번호 등 민감한 부분은 가리고 캡처할 것
